# ScoreApp quiz landing page (quiz.wrecktheroom.com)

`landing.css` restyles the ScoreApp landing page in the wrecktheroom.com black-and-gold look.
The quiz, scoring, emails and URL are unchanged.

## How to paste it
1. In ScoreApp, open the Wreck the Room scorecard and go to the **Landing page** editor.
2. Open **Settings → Custom CSS** (on some plans it's under **Advanced → Custom code**).
3. Paste the full contents of `landing.css` and **Save / Publish**.
4. Open quiz.wrecktheroom.com in a private window to check.

Tested by injecting into the live page at 1440px and 390px wide. Screenshots: `before.png`, `after-desktop.png`, `after-mobile.png`.
